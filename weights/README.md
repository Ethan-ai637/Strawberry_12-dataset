# Model Weights

This directory is reserved for the pretrained **StrawDet-YOLO** model weights associated with the paper:

> **StrawDet-YOLO: A Real-Time and High Precision Object Detection for Strawberry**  
> 2025 IEEE International Conference on Systems, Man, and Cybernetics (SMC)

## ONNX Checkpoint

The pretrained model will be released in **ONNX** format for reproducibility and deployment.

Please place the ONNX checkpoint in this directory when uploading the model weights.

Suggested filename:

```text
StrawDet-YOLO.onnx
```

Once uploaded, the repository structure will look like:

```text
weights/
├── README.md
└── StrawDet-YOLO.onnx
```
